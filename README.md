# Real-Time Chat Application

A clean browser-based real-time chat app built with **HTML**, **CSS**, and **Vanilla JavaScript**.

## ✅ Features
- Instant message sync across open browser tabs/windows
- Persistent local chat history (last 100 messages)
- Message metadata (sender + timestamp)
- Clear chat for all open tabs
- Responsive UI for desktop and mobile

## 🛠️ Tech
- HTML5
- CSS3 (Grid/Flexbox)
- JavaScript (`BroadcastChannel` + `localStorage`)

## 🚀 How to Run
Open `index.html` in your browser.

> Tip: open two tabs of the same page and chat between them in real time.
